# Configuring the client

## Configuring the client through Framework properties

The isCOBOL Framework looks for the c-tree configuration in the same file as the runtime's configuration properties unless the configuration property [iscobol.ctree.new_config (boolean)\*](../../is-cobol-evolve/SDK-Users-Guide/Compiler-and-Runtime/Configuration/Configuration-Properties#ctree_new_config) is set to false.

Properties are evaluated at the first open of a c-tree file. Changing them after the first c-tree file has been opened will have no effect.

### Global properties

The following properties affect the whole session, they can’t be set for a specific instance:

| iscobol.file.index.filepool.size | Specifies the maximum number of files that can be included in the pool. |

| iscobol.file.index.autolock_allowed (boolean) <span id="file_index_autolock_allowed"></span> | **True** = More locks on the same record can be acquired in the same run unit.<br>**False** = Only one lock on the same record can be acquired in the same run unit. <br><br>If omitted, *False* is assumed. |
