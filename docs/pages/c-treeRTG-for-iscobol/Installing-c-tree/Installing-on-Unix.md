## Installing on Unix

c-tree for other platforms comes in a gzipped tar file. The name of the file is: c-treeRTG_*vMajor.Minor.Build_Platform*.tar.gz

Current version of c-tree is:

- 5.1.1

On the Veryant website you can find portings for Linux x64 64-bit and Mac OS 64-bit.

Contact Veryant if you need a porting for other Unix platforms.

Unzip and extract the tar file with the following command:

```cobol
gunzip c-treeRTG_vMajor.Minor.Build_Platform.tar.gz
tar -xvf c-treeRTG_vMajor.Minor.Build_Platform.tar
```

A directory called c-treeRTG_*vMajor.Minor* will be created.
