### ctcmpcif

This utility can be used to encrypt and decrypt c-tree data files.

Usage:

```shell
ctcmpcif <data file name> <user> <pass> <server> <-sectors> <options>
```

Refer to c-tree Server Administrator's Guide for additional information on this utility.

Use this utility instead of [ctutil](./ctutil/ctutil) [-compact](./ctutil/compact) to compact tables that were created with SQL statements.

Use [ctutil](./ctutil/ctutil) [-compact](./ctutil/compact) to compact tables that were created by sqlizing disc files.
