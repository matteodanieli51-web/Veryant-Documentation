#### -compress

Compress a c-tree file. Compression level and strategy are read from the [<datacompress\>](../../../Configuring-the-client/Configuring-the-client-through-CTREE_CONF/datacompress) configuration entry. See [Configuring the client through CTREE_CONF](../../../Configuring-the-client/Configuring-the-client-through-CTREE_CONF/Configuring-the-client-through-CTREE_CONF) for details.

Usage

```shell
ctutil -compress file
```

  - *file* is the name of the c-tree file.
