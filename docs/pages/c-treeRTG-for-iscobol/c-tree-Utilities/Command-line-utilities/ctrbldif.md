### ctrbldif

A rebuild utility using the IFIL definitions stored in the header of a file.

Usage:

```shell
ctrbldif DataFileName [<UserId> [<Password> [<ServerName>]]] <options>
```

Refer to c-tree Server Administrator's Guide for additional information on this utility.

Use this utility instead of [ctutil](./ctutil/ctutil) [-rebuild](./ctutil/rebuild) to rebuild tables that were created with SQL statements.

Use [ctutil](./ctutil/ctutil) [-rebuild](./ctutil/rebuild) to rebuild tables that were created by sqlizing disc files.
