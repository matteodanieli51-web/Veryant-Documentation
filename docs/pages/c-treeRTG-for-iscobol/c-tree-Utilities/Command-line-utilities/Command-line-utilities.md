## Command-line utilities

The following command-line utilities are available:

- [ctadmn](./ctadmn/ctadmn)
- [ctcmdset](./ctcmdset)
- [ctcmpcif](./ctcmpcif)
- [ctdump](./ctdump)
- [ctfdmp](./ctfdmp)
- [ctfileid](./ctfileid)
- [ctldmp](./ctldmp)
- [ctpass](./ctpass)
- [ctquiet](./ctquiet)
- [ctrbldif](./ctrbldif)
- [ctrdmp](./ctrdmp)
- [ctsqlcdb](./ctsqlcdb)
- [ctsqlutl](./ctsqlutl)
- [ctstat](./ctstat)
- [ctstop](./ctstop)
- [cttctx](./cttctx)
- [cttrnmod](./cttrnmod)
- [ctunf1](./ctunf1)
- [ctutil](./ctutil/ctutil)
- [dbdump](./dbdump)
- [dbload](./dbload)
- [dbschema](./dbschema)
- [isql](./isql)
- [sa_admin](./sa_admin)

All the executable files are available in the “tools” folder except [ctutil](./ctutil/ctutil) that can be found in the “drivers/ctree.cobol/iscobol” folder of c-tree as well as in the “bin” folder of the isCOBOL SDK.
