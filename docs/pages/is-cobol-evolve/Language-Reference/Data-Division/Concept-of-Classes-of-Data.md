## Concept of Classes of Data

There are five categories of data items, described by the [PICTURE clause](./Data-Description/PICTURE-clause). These are grouped into three classes: alphabetic, numeric, and alphanumeric. For alphabetic and numeric, the classes and categories are synonymous. The alphanumeric class includes the categories of alphanumeric edited, numeric edited, and alphanumeric (without editing). Every [elementary item](./Concept-of-Levels/Concept-of-Levels) belongs to one of the classes and further to one of the categories. The class of a [group item](./Concept-of-Levels/Concept-of-Levels) is treated as alphanumeric regardless of the class of [elementary items](./Concept-of-Levels/Concept-of-Levels) subordinate to that [group item](./Concept-of-Levels/Concept-of-Levels). The following table depicts the relationship of the class and categories of data items.

| Level of item | Class | Category |
| --- | --- | --- |
| [Elementary](./Concept-of-Levels/Concept-of-Levels) | Alphabetic | Alphabetic |
| [Elementary](./Concept-of-Levels/Concept-of-Levels) | Numeric | Numeric |
| [Elementary](./Concept-of-Levels/Concept-of-Levels) | Alphanumeric | Numeric edited<br>Alphanumeric edited<br>Alphanumeric |
| [Group](./Concept-of-Levels/Concept-of-Levels) | Alphanumeric | Alphabetic<br>Numeric<br>Numeric edited<br>Alphanumeric edited<br>Alphanumeric |
