### EXCEPTION-OBJECT

EXCEPTION-OBJECT is a reference to a java.lang.Throwable object that is automatically set by the runtime each time an exception occurs.

#### General Format

```cobol
EXCEPTION-OBJECT:>methodName
```

#### Syntax Rules

1. Consult the [java.lang.Throwable](https://docs.oracle.com/javase/8/docs/api/java/lang/Throwable.html) for a list of available methods and types.à
