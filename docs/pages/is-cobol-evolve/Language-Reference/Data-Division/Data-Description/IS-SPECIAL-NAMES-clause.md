### IS SPECIAL-NAMES clause

The IS SPECIAL-NAMES clause provides an alternate way of assigning a data item to a special-name entry.

#### General format

```cobol
IS SPECIAL-NAMES {CRT STATUS    }
                 {EVENT OBJECT  }
                 {EVENT SOURCE  }
                 {EVENT STATUS  }
                 {SCREEN CONTROL}
```

#### General rules

See the [SPECIAL-NAMES Paragraph](../../Environment-Division/Configuration-Section/Special-names) of the Environment Division for a detailed explanation of each clause.
