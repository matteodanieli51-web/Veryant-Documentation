### Class condition

The class condition determines whether the content of a data item is alphabetic or numeric.

Syntax.

```cobol
identifier-1  [IS]  [NOT]  {NUMERIC}
                            {ALPHABETIC}
                            {POSITIVE}
                            {NEGATIVE}
                            {ALPHABETIC_LOWER}
                            {ALPHABETIC_UPPER}
                            {HANDLE OF} identifier-2
```
