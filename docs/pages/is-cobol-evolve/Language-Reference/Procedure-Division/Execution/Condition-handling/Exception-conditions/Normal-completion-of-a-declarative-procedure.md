#### Normal completion of a declarative procedure

A declarative procedure is said to complete normally if, during execution of the declarative procedure, none of the following occur:

1. An [EXIT](../../../../Procedure-Division-Statements/EXIT) program, [GOBACK](../../../../Procedure-Division-Statements/GOBACK), [RESUME](../../../../Procedure-Division-Statements/RESUME), or [STOP](../../../../Procedure-Division-Statements/STOP) Statement that is specified in this method or program is executed within the scope of the declarative.
2. Any directly or indirectly activated runtime element terminates the run unit.
