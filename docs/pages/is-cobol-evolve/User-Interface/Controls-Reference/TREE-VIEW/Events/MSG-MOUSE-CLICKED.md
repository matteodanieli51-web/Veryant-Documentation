## MSG-MOUSE-CLICKED

This event is fired when the user left clicks on a Tree-View item, even if the click doesn’t cause a selection change. The EVENT-DATA-2 data item contains the ID of the Tree-View item. If the Tree-View has the [Table-View](../Styles/Table-View) style, the EVENT-DATA-1 data item contains the column index.

This event is fired only if the Tree-View control has the [Notify-Mouse](../Styles/Notify-Mouse) style.
