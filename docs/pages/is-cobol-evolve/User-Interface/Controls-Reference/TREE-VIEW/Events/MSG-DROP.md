## MSG-DROP

This event is fired when the user releases the mouse left button over the control area.

The EVENT-DATA-2 data item contains the ID of the item where the event was generated.

Note - This event is fired only if the [Drag-Mode](../Properties/Drag-Mode) property is set to a value greater than zero and the Tree-View doesn’t have the [Table-View](../Styles/Table-View) style.
