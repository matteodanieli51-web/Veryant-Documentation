## MSG-MOUSE-EXIT

This event is fired when the mouse pointer is moved out of the area of Tree-View items, so when the mouse pointer is moved outside the Tree-View boundaries, over the Tree-View empty area or over the heading of a Tree-View with the [Table-View](../Styles/Table-View) style.

This event is fired only if the Tree-View control has the [Notify-Mouse](../Styles/Notify-Mouse) style.
