## Foreground-Color

This property allows you to set or retrieve the foreground color of the Chips-Box control. See "[Color management](../../../Working-With-UI-and-Controls/Creating-a-control/Color-management/Color-management)" for further details.

**Example -** Define a chips-box with a specific foreground color

```cobol
screen section.
...
  03 screen-1-chip-1 Chips-Box
     line 27.0
     column 10.0
     size 156
     lines 31
     foreground-color 13
     id 11
     .
```
