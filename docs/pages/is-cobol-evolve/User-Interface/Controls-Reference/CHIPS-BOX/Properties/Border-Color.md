## Border-Color

This property allows you to set or retrieve the border color of the Chips-Box control. See "[Color management](../../../Working-With-UI-and-Controls/Creating-a-control/Color-management/Color-management)" for further details.

**Example** - Define a chips-box control with red border

```cobol
screen section.
...
  03 screen-1-chip-1 Chips-Box
     line 35.5
     column 49.7
     size 13.1 cells
     lines 4.6 cells
     border-color 5
     id 19
     .
```
