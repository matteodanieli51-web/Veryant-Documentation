## Events

The following events are applicable to the RADIO-BUTTON control: [CMD-CLICKED](./CMD-CLICKED), [CMD-GOTO](./CMD-GOTO), [CMD-HELP](./CMD-HELP), [CMD-HELP-MOUSE](./CMD-HELP-MOUSE), [MSG-DRAG](./MSG-DRAG), [MSG-DROP](./MSG-DROP), [MSG-END-MENU](./MSG-END-MENU), [MSG-INIT-MENU](./MSG-INIT-MENU), [MSG-MENU-INPUT](./MSG-MENU-INPUT), mouse, mouse, [MSG-VALIDATE](./MSG-VALIDATE).
