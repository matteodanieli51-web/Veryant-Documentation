## MSG-MOUSE-ENTER

This event is fired when the mouse pointer is moved on List-Box items. The event may be fired multiple times if the mouse pointer hovers over multiple items before leaving the List-Box area.

This event is fired only if the List-Box control has the [Notify-Mouse](../Styles/Notify-Mouse) style.

The EVENT-DATA-1 data item contains the index of the item where the event was generated.
