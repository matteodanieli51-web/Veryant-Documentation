## Transparent

When this style is set, the title background becomes transparent.

**Example** - Define a frame with transparent title background

```cobol
screen section.
...
  03 screen-1-fr-1 Frame
     line 17.7
     column 20.0
     size 24.3
     lines 27.8 cells
     id 16
     title "Options"
     transparent.
```
