## SCROLL-BAR

![Control-Scroll-Bar](../../../images/Control-Scroll-Bar.png)

Scroll-Bars are rarely used because controls that need to scroll their content already have one. However, when the programmer needs to show information that cannot fit the screen or an area of it, he can use a Scroll-Bar; the user can move the Scroll-Bar slider to access information. Scroll-Bars can be horizontal or vertical.
