## CMD-DBLCLICK

This event Indicates that the user has double-clicked on an item in a combo-box, and that the combo-box does not have a [Termination-Value](../Properties/Termination-Value) or [Exception-Value](../Properties/Exception-Value) associated with it. This will occur only if the application requests it via the [Notify-Dblclick](../Styles/Notify-Dblclick) style. EVENT-DATA-1 is the index of the selected item in the list.
