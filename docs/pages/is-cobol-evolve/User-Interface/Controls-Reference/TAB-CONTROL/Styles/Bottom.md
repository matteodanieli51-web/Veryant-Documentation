## Bottom

When this style is set, the Tabs are positioned at the bottom. When the [Vertical](./Vertical) style is also set, the Tabs are positioned on the right side.

**Example** - Define a tab-control with bottom style

```cobol
screen section.
...
  03 screen-1-tc-1 Tab-Control
     line 2.8
     column 25.7
     size 34.6 cells
     lines 28.9 cells
     id 10
     bottom
     .
```
