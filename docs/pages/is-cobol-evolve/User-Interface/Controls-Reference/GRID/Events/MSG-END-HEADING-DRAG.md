## MSG-END-HEADING-DRAG

This event is fired when the user is dragging a header and releases the button. The EVENT-DATA-1 and EVENT-DATA-2 data items contain the column and row number (respectively) of the cell where the button has been released, as well as the [X](../Properties/X) and [Y](../Properties/Y) properties. This event works with header cells. For standard cells see the [MSG-END-DRAG](./MSG-END-DRAG) event.
