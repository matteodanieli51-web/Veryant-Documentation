## MSG-END-DRAG

This event is fired when the user is dragging a cell and releases the button. The EVENT-DATA-1 and EVENT-DATA-2 data items contain the column and row number (respectively) of the cell where the button has been released, as well as the [X](../Properties/X) and [Y](../Properties/Y) properties. This event is not fired if the user drags header cells. For this purpose see the [MSG-END-HEADING-DRAG](./MSG-END-HEADING-DRAG) event.
