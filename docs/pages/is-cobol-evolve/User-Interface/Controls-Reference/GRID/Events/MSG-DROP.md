## MSG-DROP

This event is fired when the user releases the mouse left button over the Grid area.

The EVENT-DATA-1 special register contains the X coordinate of the cell where the event was generated.

The EVENT-DATA-2 special register contains the Y coordinate of the cell where the event was generated.

Note - This event is fired only if the [Drag-Mode](../Properties/Drag-Mode) property is set to a value greater than zero.
