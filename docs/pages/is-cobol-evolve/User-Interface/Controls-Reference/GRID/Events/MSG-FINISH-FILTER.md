## MSG-FINISH-FILTER

This event is fired after the grid content has been filtered. Filtering is possible on grids with the [Filterable-Columns](../Styles/Filterable-Columns) style and grids with the [Search-Panel](../Properties/Search-Panel) property set to 0 or -1. The EVENT-DATA-2 data item contains the total number of rows in the grid: the ones that the user sees plus the ones that were hidden by the filter.
