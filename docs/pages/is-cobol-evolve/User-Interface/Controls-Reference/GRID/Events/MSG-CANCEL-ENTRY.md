## MSG-CANCEL-ENTRY

This event is fired when the Grid control is in entry mode and the user presses the [Escape] key to leave the cell. The EVENT-DATA-1 and EVENT-DATA-2 data items contain the column and row number (respectively) of the cell, as well as the [X](../Properties/X) and [Y](../Properties/Y) properties. After the user has typed the [Escape] key, the cell content is restored to the original value.
