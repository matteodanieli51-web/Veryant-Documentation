## MSG-BITMAP-DBLCLICK

This event is fired when the user double-clicks on a bitmap contained in a grid cell with the left mouse button. The values of the EVENT-DATA-1 and EVENT-DATA-2 data items represent the column and the row number (respectively) of the cell containing the bitmap, as well as the [X](../Properties/X) and [Y](../Properties/Y) properties.

Note that the event is not fired until the mouse button is released.
