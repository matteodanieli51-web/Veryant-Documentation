## BITMAP

![Control-Bitmap](../../../images/Control-Bitmap.gif)

A Bitmap is a control that shows a previously loaded image. Native and emulated transparency is supported. Native and emulated animation is supported. Emulated animation is provided using a bitmap strip and setting the [Bitmap-Start](./Properties/Bitmap-Start), [Bitmap-End](./Properties/Bitmap-End) and [Bitmap-Timer](./Properties/Bitmap-Timer) properties. A bitmap strip is a series of images of equal width that are strung together horizontally in a single bitmap file.
