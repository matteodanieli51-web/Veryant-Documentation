## NTF-CHANGED

This event is fired when the user modifies the content of an entry-field with the [Notify-Change](../Styles/Notify-Change) style set. The EVENT-DATA-1 data item contains the current cursor position in the entry-field.

It’s possible to specify a delay for this event in order to catch more changes with a single notification. Set [Notify-Change-Delay](../Properties/Notify-Change-Delay) to specify the delay.
