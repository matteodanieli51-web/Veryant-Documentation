## Transparent

When this style is set, the title background becomes transparent.

**Example** - Define a check-box with transparent title background

```cobol
screen section.
...
 03 screen-1-cb-2 Check-Box
 line 27.0
 column 10.0
 size 116
 lines 30
 id 11
 title "Sugar for you coffee?"
 transparent
     .
```
