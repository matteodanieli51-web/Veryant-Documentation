# Working With UI and Controls

isCOBOL supports all important graphical controls for realizing a complete User Interface. Please refer to the isCOBOL Appendices manual, [Graphical Control List](../../Appendices/Graphical-Control-List), to display the complete list of controls with its properties, styles and events

isCOBOL supports the following graphical controls:

- [BAR](../Controls-Reference/BAR/BAR)
- [BITMAP](../Controls-Reference/BITMAP/BITMAP)
- [CHECK-BOX](../Controls-Reference/CHECK-BOX/CHECK-BOX)
- [CHIPS-BOX](../Controls-Reference/CHIPS-BOX/CHIPS-BOX)
- [COMBO-BOX](../Controls-Reference/COMBO-BOX/COMBO-BOX)
- [DATE-ENTRY](../Controls-Reference/DATE-ENTRY/DATE-ENTRY)
- [ENTRY-FIELD](../Controls-Reference/ENTRY-FIELD/ENTRY-FIELD)
- [FRAME](../Controls-Reference/FRAME/FRAME)
- [GRID](../Controls-Reference/GRID/GRID)
- [JAVA-BEAN](../Controls-Reference/JAVA-BEAN/JAVA-BEAN)
- [LABEL](../Controls-Reference/LABEL/LABEL)
- [LIST-BOX](../Controls-Reference/LIST-BOX/LIST-BOX)
- [PUSH-BUTTON](../Controls-Reference/PUSH-BUTTON/PUSH-BUTTON)
- [RADIO-BUTTON](../Controls-Reference/RADIO-BUTTON/RADIO-BUTTON)
- [RIBBON](../Controls-Reference/RIBBON/RIBBON)
- [SCROLL-BAR](../Controls-Reference/SCROLL-BAR/SCROLL-BAR)
- [SCROLL-PANE](../Controls-Reference/SCROLL-PANE/SCROLL-PANE)
- [SLIDER](../Controls-Reference/SLIDER/SLIDER)
- [SPLIT-PANE](../Controls-Reference/SPLIT-PANE/SPLIT-PANE)
- [STATUS-BAR](../Controls-Reference/STATUS-BAR/STATUS-BAR)
- [TAB-CONTROL](../Controls-Reference/TAB-CONTROL/TAB-CONTROL)
- [TOOL-BAR](../Controls-Reference/TOOL-BAR/TOOL-BAR) \*
- [TREE-VIEW](../Controls-Reference/TREE-VIEW/TREE-VIEW)
- [WEB-BROWSER](../Controls-Reference/WEB-BROWSER/WEB-BROWSER)
- [WINDOW](../Controls-Reference/WINDOW/WINDOW) \*

\* TOOL-BAR and WINDOW can be used only in conjunction with the DISPLAY Statement.
