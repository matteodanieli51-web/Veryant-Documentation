# Compiler and Runtime

## Overview

The isCOBOL Compiler is a platform agnostic, ANSI-compliant COBOL compiler that generates object-orientated code which efficiently runs on any platform that supports a Java Runtime Environment (JRE) version 8, 11, 17 or 21. Because the isCOBOL Compiler is written 100% in Java, one COBOL compiler can be used to develop, deploy and test on a wealth of platforms including AIX, HP-UX, Linux, Solaris, Windows and mainframe systems.

Written 100% in Java, the isCOBOL Runtime Environment enables applications to able to run on any device supporting a Java Virtual Machine (JVM) -- from mainframes to mobile phones -- and this includes application logic, user interface, and data access.
