### Pop-up menu

When you right click in the Source Area, a pop-up menu appears and provides the following functions:

| Copy source code | Copies the selected line(s) in the system clipboard. The same result is achieved by pressing Ctrl+C |
| --- | --- |
| Current line | Same function as  [Edit / Current line](./Debugger-Functions) |
| Go to | Same function as [Edit / Go to...](./Debugger-Functions) |
| Continue | Same function as [Run / Continue](./Debugger-Functions) |
| Pause | Same function as [Run / Pause](./Debugger-Functions) |
| Step into | Same function as [Run / Step into](./Debugger-Functions) |
| Step over | Same function as [Run / Step over](./Debugger-Functions) |
| Step out paragraph | Same function as [Run / Step out paragraph](./Debugger-Functions) |
| Step out program | Same function as [Run / Step out program](./Debugger-Functions) |
| Run to selected line | Same function as [Run / Run to selected line](./Debugger-Functions) |
| Run to next program | Same function as [Run / Run to next program](./Debugger-Functions) |
| Jump out paragraph | Same function as [Run / Jump out paragraph](./Debugger-Functions) |
| Jump out program | Same function as [Run / Jump out program](./Debugger-Functions) |
| Jump to selected line | Same function as [Run / Jump to selected line](./Debugger-Functions) |
| Toggle breakpoint | Same function as [Breakpoints / Toggle at current line](./Debugger-Functions) |
| Display variables on selected line | Same function as [Data / Display variables on selected line](./Debugger-Functions) |
| Display... | Same function as [Data / Display](./Debugger-Functions) |
| Change value... | Same function as [Data / Accept](./Debugger-Functions) |
| Go to declaration | Same function as [Edit / Go to declaration](./Debugger-Functions) |
| Quick watch | Opens a dialog that allows you to handle the selected data item <br>![](../../../images/qw.png)  |
| Refresh Variables Area | Makes the values of the data items in the Variables Area are up to date |
