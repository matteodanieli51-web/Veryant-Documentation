### Information Window

The information window contains several tabs.

| | |
| :--- | :--- |
| Perform stack | Traces the perform stack. <br>The content grows as you step into paragraphs and called programs and reduces as you return from them. |
| Monitor | Shows monitored data items and their values. <br>These actions are permitted using the tool-bar or the context menu:<br>• create new monitors<br>• enable or disable monitors<br>• modify monitors<br>• remove monitors |
| Breakpoints | Shows breakpoints. <br>These actions are permitted using the tool-bar or the context menu:<br>• create new breakpoints<br>• enable or disable breakpoints<br>• modify monitors<br>• remove breakpoints |
| Threads | Lists active COBOL threads. <br>This view allows you to select which thread to debug. |
| Command history | Lists the commands entered so far. <br>These actions are permitted using the tool-bar or the context menu:<br>• execute a command again<br>• clear the history |
| Console <span id="console"></span> | Shows the console output.<br>Both the system output and any system errors are caught in this tab.<br>The content of the system output is shown in black.<br>The content of a system error is shown in red. <br>These actions are permitted using the tool-bar or the context menu:<br>• attach or detach the console. When detached, the output is not caught by the Debugger, going to the console of the process instead (e.g. the command prompt). Note that switching between 'attach' and 'detach' during remote debugging has no effect<br>• enable or disable the automatic activation of the Console tab when the console content changes<br>• clear the content from the window |
| | |
