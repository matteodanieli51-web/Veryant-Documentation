## TAN

The TAN function returns the tangent of a value.

### Syntax 1

```cobol
function tan (arg-1)
```

### Syntax 2

```cobol
$tan (arg-1)
```

### Arguments

- *arg-1* must be a numeric data item or literal.

### Result

The function returns a number that is the tangent of arg-1.

### Examples

**Example -** Display the tangent of 1.

```cobol
display function tan(1).
```
