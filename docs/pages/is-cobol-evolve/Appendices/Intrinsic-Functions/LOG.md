## LOG

The LOG function returns the logarithm of a number.

### Syntax 1

```cobol
function log (arg-1)
```

### Syntax 2

```cobol
$log (arg-1)
```

### Arguments

- *arg-1* must be a data-item.

### Result

The function returns the logarithm of arg-1.

### Examples

**Example -** Display the logarithm of the number 100.

```cobol
display function log(100).
```
