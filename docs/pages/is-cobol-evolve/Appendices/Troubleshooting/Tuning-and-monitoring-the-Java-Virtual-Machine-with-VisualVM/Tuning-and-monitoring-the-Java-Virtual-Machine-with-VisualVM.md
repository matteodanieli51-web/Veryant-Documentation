## Tuning and monitoring the Java Virtual Machine with VisualVM

VisualVM is a Java virtual machine monitoring, troubleshooting, and profiling tool.

The VisualVM tool can be downloaded from [visualvm.github.io](https://visualvm.github.io/download.html).

In this chapter we're going to see how to monitor the JVM activity and the load using the VisualVM tool.

Note that the information in this chapter are applicable to the Oracle JDK. Different JDK distributions may have different tools or options.
