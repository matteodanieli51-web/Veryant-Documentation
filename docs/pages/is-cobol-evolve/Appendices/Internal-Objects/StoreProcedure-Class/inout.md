### inout

Defines an input-output parameter forthe subroutine.

#### General format

```cobol
StoreProcedure inout (parm)
```

#### Syntax rules

1. *parm* is any COBOL data item
2. *StoreProcedure* is an object reference to com.iscobol.lib.StoreProcedure

#### General rules

3. An input-output parameter can be read and modified by the COBOL subroutine.
