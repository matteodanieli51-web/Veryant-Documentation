### WPROGRESSDIALOG-DESTROY

The WPROGRESSDIALOG-DESTROY function destroys the progress dialog box.

#### Syntax:

```cobol
 CALL "W$PROGRESSDIALOG" USING WPROGRESSDIALOG-DESTROY
                               pDialogHandle
```

#### Parameters:

|  |  |  |
| --- | --- | --- |
| WPROGRESSDIALOG-DESTROY | Constant |  |
| *pDialogHandle* | HANDLE | Handle returned by [WPROGRESSDIALOG-CREATE](./WPROGRESSDIALOG-CREATE). |
