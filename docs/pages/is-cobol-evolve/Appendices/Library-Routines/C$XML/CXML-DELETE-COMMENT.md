### CXML-DELETE-COMMENT

The CXML-DELETE-COMMENT function removes comments from XML elements or document.

#### Syntax:

```cobol
 CALL "C$XML" USING CXML-DELETE-COMMENT
                    handle
```

#### Parameters:

|  |  |  |
| --- | --- | --- |
| *CXML-DELETE-COMMENT* | Constant |  |
| *handle* | USAGE HANDLE | A XML element or parser handle. |
