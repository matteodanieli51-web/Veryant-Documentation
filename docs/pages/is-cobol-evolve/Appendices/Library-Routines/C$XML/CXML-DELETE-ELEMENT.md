### CXML-DELETE-ELEMENT

The CXML-DELETE-ELEMENT function deletes an element.

#### Syntax:

```cobol
 CALL "C$XML" USING CXML-DELETE-ELEMENT
                    handle
```

#### Parameters:

|  |  |  |
| --- | --- | --- |
| *CXML-DELETE-ELEMENT* | Constant |  |
| *handle* | USAGE HANDLE | A XML element handle. It specifies the element to delete. |
