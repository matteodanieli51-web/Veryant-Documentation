# Runtime Options and Configuration

In order to assign one or more indexed file to the DatabaseBridge at runtime, set the following configuration properties:

| | |
| --- | --- |
| iscobol.easydb.commit_count | This property should be set to 1 unless you wish to manage transactions with COMMIT and ROLLBACK statements. See Transactions for more details. |
| iscobol.easydb.prefix=<prefix\> | Instructs the runtime to call EDBI routine whose name begins with. <br>Possible values are the default values used at compile time:<br>• db2<br>• d24<br>• gen<br>• ifx<br>• ora<br>• mys<br>• pgs<br>• srv <br>If you used a different prefix by setting *iscobol.compiler.easydb*..prefix at compile time, use the same prefix here. <br>**Note** - This property must not be set if the EDBI routines were generated by the EDBIIS command. |
| iscobol.file.index.*physicalfilename*=easydb | Redirects all I/O of physicalfilename to the appropriate EDBI routine. <br>For example, setting <br>*iscobol.file.index.invoice=easydb* <br>means that the Dynamic Filesystem Interface will redirect all I/O done from any COBOL program that uses “invoice” as a physical file name (SELECT INVOICE ASSIGN TO “invoice”) to the EDBI-invoice routine. |
| iscobol.file.index=easydb | Redirects all I/O to the appropriate EDBI routine |
| iscobol.jdbc.autocommit | This property should be kept to the default value of false, so it shouldn’t appear in a runtime configuration for Database Bridge. |
| | |
