## Download and install the Java Development Kit (JDK)

A JDK must be installed on your machine in order to use isCOBOL DatabaseBridge. For best results and performance, install the latest JDK version available for your platform.

isCOBOL DatabaseBridge is certified for use with both Oracle JDK and OpenJDK, supporting the following LTS versions: 8, 11, 17, and 21.

**Note** - Using Java 21 the default encoding is UTF-8 on every operating system.

Self-extracting setups are provided for the Windows platform.

On Unix/Linux platforms Java may be already installed. If it’s not the case, you can install it using the appropriate system commands (e.g. yum, or apt-get).
