## Download and install Tomcat

The Apache Tomcat main page is [http://tomcat.apache.org/](http://tomcat.apache.org/) .

Here are some steps to download and install Tomcat 10 on Windows:

**NOTE** - To avoid problems, uninstall earlier versions of the Tomcat service before installing Tomcat 10.

- Make sure that you already have installed JDK 8 (or greater) and isCOBOL Evolve
- Visit [https://tomcat.apache.org/download-80.cgi](https://tomcat.apache.org/download-80.cgi).
- Find the Binary Distributions section and click on the *32-bit/64-bit Windows Service Installer* link
- Run the downloaded executable file and follow the prompts accepting the defaults
