# Command-line usage

isCOBOL IDE implements some command-line switches that allow you to perform tasks in background mode, without user interaction.

The following tasks can be performed:

- [Generate and build projects](./Generate-and-build-projects)
- [Import AcuBench/Totem programs (PSF and CPF)](./Import-AcuBench-Totem-programs-PSF-and-CPF)
- [Import AcuBench/Totem file layout (DLT and CLF)](./Import-AcuBench-Totem-file-layout-DLT-and-CLF)
- [Import SL/FD copy files](./Import-SL-FD-copy-files)
- [Import COBOL program](./Import-COBOL-program)
- [Import isCOBOL Data Layout](./Import-isCOBOL-Data-Layout)
- [Import isCOBOL Screen Program](./Import-isCOBOL-Screen-Program)
- [Import RM WOW Project](./Import-RM-WOW-Project)
- [Import RM WOW Program](./Import-RM-WOW-Program)

**Note** - Although only a few major options are shown in this documentation for your convenience, all the Eclipse command line options can be used. Refer the the Eclipse documentation for further details.
