#### TAB CONTROL’S PAGE

| Properties | |
| --- | --- |
| (name) | Specifies the page name. This property is set automatically when the page is added |
| bitmap-number | Specifies the value for the *Bitmap-Number* property |
| enabled | TRUE... *Tab-Enabled* is not generated<br>FALSE... *Tab-Enabeld=0* is generated |
| tab-hint | Specifies the value for the *Tab-Hint* property |
| tab order | Sets the ordinal position of the page in the Screen Section. This property is set automatically when the page is added |
| tab width | Specifies the value for the *Tab-Width* property |
| title | Specifies the page title |

| Variables | |
| --- | --- |
| tab-hint variable | Alphanumeric variable that hosts the value for the *Tab-Hint* property |
| tab-width variable | Numeric variable that hosts the value for the *Tab-Width* property |
| title variable | Alphanumeric variable that hosts the page title |
| visible variable | Numeric variable that hosts the page visibility |
