## Generating Dictionaries

The IDE can generate EFD and ISS dictionaries from a file layout.

EFD dictionaries can be generated for all kind of files.

ISS dictionaries can be generated only for indexed files.

To generate a dictionary, right click on the fd name in the isCOBOL Explorer and choose either *Make EFD File* or *Make ISS File* from the pop-up menu. The same options are also available under *Generate* in the menu bar.

Dictionaries are generated in the folder specified by the -efo compiler option in project settings.

If the -efo option was not configured, then dictionaries are generated in the *data* folder of the project.
