### Alternate JAVA JRE

If you linked one or more external JREs to the IDE, you can choose which one to use for the current project. Select *isCOBOL Settings > Java Runtime* in order to get the list of available JREs and check the one you wish to use.

See [Binding additional JRE](../../Configuration/Customization/Binding-additional-JRE) for more information about how to add external JREs to the IDE.
