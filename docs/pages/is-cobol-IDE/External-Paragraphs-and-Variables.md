# External Paragraphs and Variables

isCOBOL IDE sets some paragraphs and variables as external. This means that even if they’re declared in the Screen Program sections, the IDE will not generate them, assuming that they’re available in the copybooks added by the user.

In order to set some variables and paragraphs as external

1. Right click on the program name in the Structural View.
2. Choose *External Settings* from the pop-up menu.

It’s also possible to define external paragraphs and variables in [Screen Program properties](./Screen-Programs/Screen-Program-properties).
