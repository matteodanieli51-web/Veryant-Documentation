## Launching isCOBOL Utilities

1. Click on “isCOBOL Tools” in the menu bar.
2. Select “Utilities”.
3. Select one of the utilities to show a dialog that allows you to set the utility up and launch it:

| | |
| --- | --- |
| Index and Relative File Editor (GIFE) | ![](../images/IDE-uti-gife.png) |
| Index File Migration (ISMIGRATE) | ![](../images/IDE-uti-ismigrate.png) |
| Create FD from RDBMS (JDBC2FD) | ![](../images/IDE-uti-jdbc2fd.png) |
| Color Picker (CPK) | ![](../images/IDE-uti-cpk.png) |
| Working Storage from Stream (STREAM2WRK) | ![](../images/IDE-uti-stream2wrk.png) |
| isCOBOL Launcher (ISL) | ![](../images/IDE-uti-isl.png) |
| JavaBean Copy Generator (CPGEN) | ![](../images/IDE-uti-cpgen.png) |
| COBOL File IO Class generator (COBFILEIO) | ![](../images/IDE-uti-cobfileio.png) |
| Jisam File Utility (JUTIL) | ![](../images/IDE-uti-jutil.png) |
| | |

Graphical utilities (like CPK or ISL) appear over the IDE’s window.

Command line utilities (like STREAM2WRK or JUTIL) show their output in the [Console](../The-isCOBOL-IDE-Perspective/Console) view.
