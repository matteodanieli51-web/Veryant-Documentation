## Managing LoadBalancer

1. Click on “isCOBOL Tools” in the menu bar.
2. Select “LoadBalancer”.
3. Select the desired action:

| | |
| --- | --- |
| *Start* | Start the LoadBalancer; the output is shown in the Console View. ![](../images/bal_started.png) |
| *Stop* | Stop the LoadBalancer; the Console View is cleaned. ![](../images/bal_stopped.png) |
| *Restart* | Stop and start the LoadBalancer; the output is shown in the Console View. ![](../images/bal_started.png) |
| | |

LoadBalancer settings can be configured in the *Preferences* menu. See [LoadBalancer Settings](../Configuration/Customization/Configuring-isCOBOL-tools#loadbalancer-settings) for more information.
