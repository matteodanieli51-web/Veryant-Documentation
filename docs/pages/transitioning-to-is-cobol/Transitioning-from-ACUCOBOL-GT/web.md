## Web

- CGI programs developed with ACUCOBOL-GT can be easily transformed into Java Servlets. See [Conversion of the ACUCOBOL-GT Oscars sample](../../is-cobol-EIS/COBOL-Servlet-option-OOP/COBOL-Servlet-Programming-to-replace-CGI-COBOL-programming#conversion-of-the-acucobol-gt-oscars-sample) in the EIS documentation for details.
- COBOL program working with the ACUCOBOL-GT Web Runtime or AcuToWeb can be run using isCOBOL WebClient. See [isCOBOL Evolve: WebClient](../../is-cobol-web-client/Key-Topics) for details.
