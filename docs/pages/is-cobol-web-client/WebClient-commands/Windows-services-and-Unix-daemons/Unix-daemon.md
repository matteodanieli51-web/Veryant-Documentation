### Unix daemon

On Linux systems, WebClient tools can be installed as daemon processes and maintained using the following commands: [webclient-admin](../webclient-admin), [webclient-and-admin](../webclient-and-admin), [webclient-cluster](../webclient-cluster), [webclient-session](../webclient-session) and [webclient](../webclient)

Each command provides the following options:

| Option | Action |
| --- | --- |
| run | Run the daemon in foreground mode. |
| start | Run the daemon in background mode. |
| stop | Stop the daemon. |
| restart | Stop and start again the daemon in background mode. |
| status | Show the daemon status. |
| env | Pint the current environment settings |

#### Daemon configuration

WebClient tools on Linux look for two files located in the bin directory:

- *default_java.conf* includes the paths to the WebClient and Java installations:

| Variable | Description |
| --- | --- |
| ISCOBOL | WebClient installation directory |
| ISCOBOL_JDK_ROOT | JDK installation directory |
| ISCOBOL_JRE_ROOT | JRE installation directory |

- *<command\>.options* includes environment variables that can alter the command behavior:

| Variable | Description |
| --- | --- |
| *PREFIX*_HOME | Home directory of the command |
| *PREFIX*_OPTS | Command line options for the command.<br>Use a space to separate multiple options.<br>When the options string includes spaces, delimit it with quotes, for example:<br>WEBCLIENT_OPTS="-p 1234 -c mywebc.config" |
| *PREFIX*_JAVA_EXE | Alternative JVM for the command |
| *PREFIX*_JAVA_OPTS | Java options for the command.<br>Use a space to separate multiple options.<br>When the options string includes spaces, delimit it with quotes, for example:<br>WEBCLIENT_JAVA_OPTS="XX:+HeapDumpOnOutOfMemoryError -Xmx4G". |
| *PREFIX*_LOG_FILE | File where the command output is redirected |
| *PREFIX*_PID_FILE | Semaphore file to inform if the command is running or not.<br>This file contains the process ID. |

Depending on the *<command\>.options* file, PREFIX can be:

- WEBCLIENT for webclient
- WEBCLIENT_ADMIN for webclient-admin
- WEBCLIENT_CL for webclient-cluster
- WEBCLIENT_SP for webclient-session

These files are generated by the setup process.

In these files, comments are prefixed by a hash and each entry is on a separate line.

Environment variables in *<command\>.options* can alternatively be set also in the external environment through the export command. The external environment has priority over the content of *<command\>.options*.

### Starting multiple daemons on the same machine (Unix)

In this example we show how to start two WebClient daemons listening on different ports on the same machine.

1. Create the two daemons as follows:

```cobol
export WEBCLIENT_OPTS=-p 8080 -c /path/to/webclient1.config
export WEBCLIENT_PID_FILE=webclient1.pid
webclient start
 
export WEBCLIENT_OPTS=-p 8081 -c /path/to/webclient2.config
export WEBCLIENT_PID_FILE=webclient2.pid
webclient start
```

**Note** - the two commands above show the basic options; you might improve them with additional options from [Command-line startup options](../Command-line-startup-options).

2. To stop the two daemons, do the following:

```cobol
export WEBCLIENT_PID_FILE=webclient1.pid
webclient stop
 
export WEBCLIENT_PID_FILE=webclient2.pid
webclient stop
```
