# Getting Started

The setup of the development environment requires the following steps:

1. [Download and install the Java Development Kit (JDK)](./download-JDK)
2. [Download and install the isCOBOL Evolve SDK](./download-isCOBOL-Evolve)
3. [Download and install Visual Studio Code](./download-VSCode)
4. [Download and install the Veryant isCOBOL extension](./download-Veryant-isCOBOL-extension)
5. [Activate the License](./activate-license)

In order to activate your isCOBOL Evolve products, you will need the e-mail you received from Veryant containing your license key. Contact your Veryant representative for details.
